# Driver Panel

RestroMatrix Driver application for managing deliveries and tracking orders.

## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The server will start at `http://localhost:5176` (or the next available port).

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

### Linting

```bash
npm run lint
```

## Technologies

- **React 19** - User interface
- **Vite** - Build tool
- **React Router** - Navigation
- **Axios** - HTTP client
- **Socket.io** - Real-time communication
- **Leaflet** - Map integration
